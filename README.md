# 📊 Trading Dashboard — Sakib Khan

A personal trading dashboard for BTC & Gold (XAU/USD): live prices, live charts, market sentiment, key levels, and a countdown to the next high-impact news event — all on one screen.

**Live version:** https://muse.ai/s/trading-dashboard-xsxi6xdfxlw2wxha/8dtRBrUQLEc0VIbPXpZl_xLo9kiJMYhJyYFdx-WL-po

You can also open `index.html` directly in any browser — it is a single self-contained page with no build step.

## What's inside

- **Bitcoin (BTC/USD)** — live price, 24h change, 24h high/low and volume (CoinGecko)
- **Gold (XAU/USD)** — live spot price per troy ounce (gold-api.com)
- **Fear & Greed Index** — current value with a sentiment gauge (alternative.me)
- **Live charts** — TradingView daily charts for BTC/USDT and XAU/USD
- **Key levels** — support & resistance levels from the latest daily analysis (dated in the page)
- **High-impact events** — upcoming US macro events in Asia/Dhaka time with a live countdown to the next one

Prices and sentiment auto-refresh every 60 seconds. All times are shown in Asia/Dhaka (GMT+6).

## Data sources

CoinGecko · gold-api.com · alternative.me · TradingView — all free public APIs, fetched in the browser. No API keys, no server, no tracking.
